# FreelanceHub - Freelancing Marketplace

A modern, responsive freelancing marketplace where clients can post projects and freelancers can browse opportunities, submit proposals and manage their activity from a dashboard.

Built as part of the Web Development Internship (Project Phase 2) at Sqrock IT Solutions.

## Live Demo



## Features

- **Homepage:** hero section, platform introduction, popular categories, featured projects and featured freelancers
- **Project listing:** project cards with category, budget, skills, deadline and client
- **Search and filters:** search projects by title, filter by category and budget range
- **Freelancer profiles:** photo, title, rating, expertise level, bio, skills and portfolio samples
- **Freelancer search:** search by skill and filter by expertise level
- **Project details page:** full description, required skills, budget, deadline and client details
- **Proposal form:** name, email, expected budget and cover letter, with validation and clear error messages
- **Dashboard:** summary statistics, profile, posted projects with status badges and submitted proposals
- **LocalStorage:** submitted proposals are saved in the browser and shown on the dashboard
- **Responsive design:** works on mobile, tablet and desktop, with a hamburger menu on small screens

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- JavaScript (ES6)
- LocalStorage

## How to Run Locally

1. Clone the repository:
   `git clone https://github.com/Elizabeth-star-tech/freelancehub-marketplace.git`
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or double-click it to open it in your browser.

No installation or build step is needed.
